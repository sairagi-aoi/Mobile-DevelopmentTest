# Claude Tasks（by Claude）

> このアプリは **Claude（Anthropic）/ Claude Code** が作成しました。
> リポジトリ直下にある Codex 作の「ひとつずつ — Tiny Tasks」とは別のプロダクトです。

iPhoneでの利用に特化した、シンプルなタスク管理Webアプリです。HTML・CSS・JavaScriptのみで動作し、ビルドや外部ライブラリー、アカウント登録は不要です。

## 特長

- **モバイルファースト**：入力欄を親指の届く画面下部に固定。タップ領域は44px以上、入力欄は16px（iOS Safariの自動ズームを防止）
- **iPhone対応**：ノッチ・ホームインジケーターのセーフエリア、ダークモード、ホーム画面への追加（`apple-mobile-web-app-*`）に対応
- **ローカル保存**：`localStorage` に自動保存。サーバー送信なし
- **タスクの追加・編集・完了・削除**（削除は「元に戻す」可能）

## 起動方法

リポジトリのルートで次を実行します（Python 3が必要）。

```sh
python3 -m http.server 8000 --bind 0.0.0.0 --directory apps/claude-tasks
```

- PC：`http://localhost:8000` を開く
- iPhone：PCと同じWi-Fiに接続し、Safariで `http://<PCのローカルIPアドレス>:8000` を開く

GitHub Pagesなどの静的ホスティングに `apps/claude-tasks/` をそのまま配置しても動作します。
Safariの共有ボタン →「ホーム画面に追加」で、アプリのように起動できます。

## 使い方

| 操作 | 方法 |
| --- | --- |
| **追加** | 画面下の「タスクを追加」に入力し、＋ボタンまたはキーボードの完了キー。続けて入力できます |
| **完了** | タスク左の丸いチェックをタップ。もう一度タップで未完了に戻ります |
| **編集** | タスク名をタップ → シートでタイトル・メモ・完了状態を変更して「保存」。「キャンセル」や背景タップでは保存されません |
| **削除** | 編集シートの「このタスクを削除」。直後に表示される「元に戻す」で復元できます |
| **絞り込み** | 上部の「未完了」「完了」「すべて」で切り替え。「すべて」では未完了 → 完了の順に表示 |
| **完了済みの一括削除** | 「完了」または「すべて」表示で「完了したタスクを削除」（「元に戻す」可） |

- タイトルは必須・200文字まで（前後の空白は除去）、メモは2,000文字まで
- 新しいタスクは一覧の先頭に追加されます。完了済みは完了日時の新しい順に並びます
- 上部に残り件数と完了数を表示します

## データ保存

- 保存先：ブラウザーの `localStorage`、キー `claude-tasks:v1`
  - Codex版（`tiny-tasks:v1`）とは別キーのため、同じオリジンで両方を使ってもデータは混ざりません
- 形式：`{ "version": 1, "tasks": [{ id, title, note, done, createdAt, updatedAt, completedAt }] }`
- 同じアプリを開いた別タブの変更も自動で反映します
- 保存に失敗した場合（容量不足など）はメッセージを表示し、画面と入力内容を操作前のまま保持します
- 読み込めない保存データは削除せず `claude-tasks:v1:corrupt-<時刻>` に退避してから、新しいリストで起動します
- データは利用中のブラウザー・端末の中だけに保存されます。端末間の同期やバックアップはありません。Safariの「履歴とWebサイトデータを消去」などで失われます

## 動作確認（テスト）

Python版Playwright + Chromiumで、iPhone 13相当の画面（390×664、タッチ操作）で実際にブラウザーを動かして確認します。

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 apps/claude-tasks/tests/test_app.py
```

インストール済みのChromiumを使う場合：

```sh
CHROMIUM_PATH=/path/to/chromium python3 apps/claude-tasks/tests/test_app.py
```

確認内容（18件）：

- レイアウト：横スクロールなし、入力欄16px、ボタン44px以上、入力欄が画面下部に固定
- 追加：前後空白の除去、空白のみの拒否、HTMLを文字列として表示（XSS対策）、200文字の長いタイトル
- 完了：完了/未完了の切り替え、完了日時の記録、フィルター表示
- 編集：タイトル・メモ（複数行）・完了状態の保存、キャンセル時に変更しない、空タイトルの拒否
- 削除：個別削除と「元に戻す」、完了済みの一括削除
- 保存：再読み込み後の復元、Codex版データに触れない、破損データの退避、保存失敗時の状態保持、別タブへの反映

実機SafariでのタッチやキーボードUI、セーフエリアの見え方は、iPhone実機での最終確認を推奨します。
