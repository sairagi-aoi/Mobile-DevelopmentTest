# ひとつずつ — Tiny Tasks

iPhoneで手軽に使える、日本語のシンプルなタスク管理Webアプリです。HTML・CSS・JavaScriptのみで構成し、ビルドやアカウント登録は不要です。

## 起動方法

PCでこのリポジトリを取得し、リポジトリのディレクトリで次のコマンドを実行します（Python 3が必要）。

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

PCでは `http://localhost:8000` を開きます。iPhoneでは、PCと同じWi-Fiに接続し、Safariで `http://<PCのローカルIPアドレス>:8000` を開いてください。接続できない場合はPCのファイアウォール設定を確認してください。サーバーは `Ctrl+C` で停止できます。

静的ホスティングにも、そのまま配置できます。`index.html` を直接開くこともできますが、`file://` での保存動作はブラウザーによって異なるため、HTTP/HTTPSでの利用を推奨します。対象はiOS 16以降のSafariと、現行の主要ブラウザーです。

## 使い方

- **追加**：画面下の「次にやることは？」に入力し、＋ボタンまたはキーボードの完了キーを押します。
- **編集**：タスク名をタップし、内容を変更して「保存する」を押します。キャンセルや閉じるボタンでは変更を保存しません。
- **優先度**：編集画面で「高（赤）」「中（オレンジ）」「低（青）」を選び、「保存する」を押します。フラグと優先度の文字を表示し、タスク行全体を同じ色系統で塗ります。「なし」で解除できます。新しいタスクの初期値は「なし」です。
- **メモ**：編集画面の「メモ」に手順や補足を入力できます。改行を含め10,000文字まで保存でき、一覧には冒頭のプレビューを表示します。
- **子タスク**：各タスクの右側の＋をタップすると、そのタスクの子を追加できます。子にさらに子を追加することもできます。
- **親の変更**：編集画面の「親タスク」で変更できます。「親なし」を選ぶと独立したタスクになります。自分自身や自分の子孫は選べません。
- **完了**：タスク左の丸いチェックをタップします。もう一度タップすると未完了に戻せます。
- **表示切り替え**：「すべて」「未完了」「完了」でタスクを絞り込みます。
- **削除**：編集画面で「このタスクを削除」を押し、確認後に「削除する」を押します。

タスク名は空白だけでは登録できず、200文字まで入力できます。画面下から追加したタスクは一覧の先頭、子タスクは親の子一覧の末尾に表示されます。上部のカードで、親・子を含む全タスクの未完了数と完了率を確認できます。表示される日付は今日の日付で、タスクは日付が変わっても残ります。

親と子の完了状態はそれぞれ独立しています。絞り込み時には、対象の子タスクを持つ親も「親タスク」として表示し、件数は条件に合うタスクだけを数えます。親を削除しても子は削除せず、削除した親の親へ移します。最上位の親を削除した場合、直接の子は独立したタスクになります。孫以下の関係とメモは保持します。

優先度も親と子で独立して設定できます。子タスクを作るときにも選べます。完了後もフラグと色を保持し、編集・移動・表示切り替え・再読み込みで失われません。優先度を変更しても並び順は変わりません。

## ドラッグで移動する

「すべて」を選び、行の右端の **⠿** を指またはマウスでつかんで移動します。タスク名をなぞる操作はスクロールとして使えます。

- 移動先の行の**上端**に置く：そのタスクの前へ移動します。
- 移動先の行の**下端**に置く：そのタスクと子孫の後ろへ移動します。
- 移動先の行の**中央**に置く：そのタスクの子として、子一覧の末尾へ移動します。
- ドラッグ中に画面上部に出る**「親なしにする」領域**に置く：独立したタスクとして全体の末尾へ移動します。

子孫は親と一緒に移動します。別の親の子の前後に置くと、その子と同じ親になります。画面の上端・下端付近では自動スクロールします。移動先のハイライトと案内を確認して指を離してください。自分自身や子孫への移動、一覧外へのドロップ、タッチのキャンセルでは保存データを変更しません。PCでは `Esc` でもキャンセルできます。

キーボードでは⠿にフォーカスし、`↑` / `↓` で同じ親の中を並べ替え、`→` で直前のタスクの子に、`←` でひとつ上の階層に移動できます。絞り込み中の移動ハンドルは無効になります。親の変更は編集画面からも行えます。

## データ保存

追加・編集・完了・削除・移動は、成功するたびにブラウザーの `localStorage`（既存キー：`tiny-tasks:v1`、データ形式：version 3）へ保存され、親子関係・メモ・優先度・並び順も再読み込み後に復元されます。同じURLを開いた別タブの変更も反映します。保存失敗時にはエラーを表示し、操作前の状態と入力内容を保持します。読み込めない保存データや、循環・存在しない親・不正な優先度を持つデータを自動で上書きすることはありません。

以前のversion 1のタスクは、ID・タイトル・完了状態・作成日時・並び順を引き継ぎ、親なし・メモなし・優先度なしとして読み込みます。version 2は親子関係とメモも引き継ぎ、優先度なしとして読み込みます。読み込みだけでは保存データを変更せず、初回の変更を保存するとversion 3へ移行します。古いアプリを開いたままのタブは更新してください。古いアプリではversion 3は読み込めませんが、データを上書きしません。

公開後に操作ボタンが表示されない場合は、Safariでページを再読み込みしてください。JS・CSSのURLには版を示すクエリを付けています。今後これらのファイルを変更して公開するときは、`index.html` 内の4つの `v` を同時に更新し、古いファイルのキャッシュとの混在を防いでください。

データは利用中のブラウザー・端末・オリジン（プロトコル、ホスト、ポート）の中だけに保存されます。サーバーへの送信や端末間の同期、バックアップ、オフライン起動は実装していません。サイトデータの削除やプライベートブラウズ終了などで失われる場合があります。保存データの破損で起動できない場合は、必要に応じて元データを退避してから、このサイトのデータをブラウザー設定で削除してください。

## ファイル構成

```text
index.html          画面と編集ダイアログ
styles.css          モバイルファーストのスタイル
app.js              タスク操作・保存・表示
task-model.js       保存形式・親子関係・並び順の処理
task-drag.js        タッチ・マウス・キーボードでの移動
icon.svg            アプリアイコン
tests/browser_smoke.py  ブラウザーによる動作確認
```

iPhoneのセーフエリアに対応し、主要な操作領域は44px以上、テキスト入力は16pxにしています。ページのズームは制限していません。キーボード操作、読み上げ用ラベル、操作結果の通知にも対応しています。

## 動作確認

自動テストはPython版PlaywrightとChromiumを使用します。アプリ自体に外部ライブラリーは不要です。

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
python3 tests/browser_smoke.py
```

システムにインストール済みのChromiumを使う場合：

```sh
CHROMIUM_PATH=/usr/bin/chromium python3 tests/browser_smoke.py
```

テストは一時的なローカルHTTPサーバーを起動し、iPhone相当の画面サイズで追加・編集・キャンセル・完了・絞り込み・削除・保存復元を確認します。優先度の設定・解除・色分け・親子での独立設定・保存失敗時の保持、親子・孫関係、複数行メモ、version 1/2からの移行、親削除時の子の保持、マウスとブラウザーへのタッチ入力によるドラッグ、親の変更、キーボード移動、自動スクロールとキャンセル、循環防止、破損データ、別タブ更新、深い階層での横方向のはみ出しも確認します。実機Safariでの指操作・キーボード・セーフエリアの最終確認は別途必要です。
